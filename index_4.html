What's inside

Everything you'd expect from a real OS.

Each feature was written from scratch — the GUI compositor, the network stack, the drivers, all of it.

🖥️
Custom GUI Compositor
Window compositing with real drop shadows, maximize/resize, animations, and a macOS-style floating taskbar.
🌐
Real Network Stack
RTL8139 and Intel e1000 driver support. Ethernet → ARP → IP → TCP → DHCP → DNS — all written from scratch.
🤖
Luigi AI Assistant
A bare-metal AI that evaluates math, detects TR/EN automatically, and answers questions about the OS — no cloud required.
🗂️
Virtual File System
RAM-based VFS with 128 nodes, real file read/write, directory hierarchy, and persistence across apps.
🎮
XaefGAMES
Snake, Tetris, Pong, and Minesweeper — playable games running on hardware-accurate PIT timing, not CPU speed.

Developer Mode
10 unlockable dev tools: memory viewer, port I/O tester, VFS inspector, CPU registers, IRQ monitor, and more.
